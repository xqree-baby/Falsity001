────────── 为什么 git status 前后都是干净的 ──────────
  坏版做在 day26-out/bad-version/ 独立目录,从未污染 public/。
  → 工作区本来就是v1.0, 没有东西可退, status自然干净。
  → 退出码 0 只说明「文件已是你要的那版」,不说明「它曾经是坏的」。
  → 所以静态托管回退的本质 = 把 git 里的那份原样重传一遍。
