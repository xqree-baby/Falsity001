### 过程中发现并修掉的 2 个真bug

1. **自污染（严重）**：HTML 报告里会印出被检出的密钥字面量，下一轮扫描把**自己的报告**当成新泄漏 → 退出码永远回不到 0。
   - 第一次修错：排除名单写死了 `release-check-out`，而实际输出目录是 `day25-out`，没修住。
   - 第二次也修错：改用「目录里同时有 `check*.html` 和 `check-*.txt`」判定——**这个假设是虚构的**，实测发现 txt 全写在仓库根目录，目录里只有 html。
   - 最终修法：**不再靠目录特征猜**，改为按**文件名特征**排除本工具生成的 `check*.html|check-*.txt`，与目录名无关。
   - 教训：判据不能靠猜目录特征。这是今天「穷举优于猜」的第四次同源印证。

2. **`sed` 副作用**：`sed -i` 注入时顺手把 `''` 改成了 `""`，留下一处与任务无关的 diff。已用 `git checkout -- functions/api/db.js` 回滚，**确认 diff 为空、假密钥零残留**（`git status`/`git diff` 均无该文件）。
