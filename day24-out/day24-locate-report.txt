【候选原因清单】发帖点发布返回 404，可能的原因：
  H1 前端用了相对路径，请求打到静态托管而不是网关
  H2 后端没注册 POST /posts 这条路由
  H3 网关没绑定这条路由（请求压根到不了函数）
  H4 跨域被拦（Day 20 老坑：ACAO 配两遍）
  H5 表单字段缺失被后端拒（400 类）
  H6 静态托管没重新部署，跑的是旧前端
  H7 后端整体挂了 / 数据库连不上
  H8 线上代码版本比本地旧（Day 23 未部署）

[★ 命中] H1 前端相对路径打到静态托管
         判据：POST https://falsity-mock005-falsity001-d1gowkogp40251a26.webapps.tcloudbase.com/api/posts => 404，content-type=text/html。静态托管里没有 /api，返回的是 HTML 404 页面（CloudBase 自己的 404 页）。

[★ 命中] H2 后端没注册 POST /posts 路由
         判据：POST https://falsity001-d1gowkogp40251a26-1499370664.ap-shanghai.app.tcloudbase.com/api/posts => 404，返回体 {"ok":false,"error":"not found","receivedPath":"/api/posts"}。receivedPath 是自家函数的字段 → 请求已进函数，是函数自己说'没这条路由'，不是网关拦的。

[已排除] H3 网关没绑定这条路由
         判据：GET https://falsity001-d1gowkogp40251a26-1499370664.ap-shanghai.app.tcloudbase.com/api/posts => 200。同一路径 GET 通得了，说明路径已绑定；且 Day 22 实测过网关按路径绑定不区分方法，POST 同路径不用多绑。

[已排除] H4 跨域被拦（ACAO 配两遍）
         判据：响应头 Access-Control-Allow-Origin: https://falsity-mock005-falsity001-d1gowkogp40251a26.webapps.tcloudbase.com。只有一个值、没逗号拼接 → 没配重；而且这次请求拿到了 404 状态码（跨域被掐时 JS 侧根本读不到状态码，只剩 Failed to fetch）。

[已排除] H5 表单字段缺失被后端拒
         判据：POST 网关/posts 空 body => 404。404 而不是 400，且请求连路由都没匹配上，轮不到字段校验。

[已排除] H6 静态托管跑的是旧前端
         判据：静态托管首页 HTML 里能搜到 API_BASE 常量（网关域名）。能搜到说明静态托管是 Day 20 之后部署的，前端整体不旧——只是发帖那一段漏改了。

[已排除] H7 后端整体挂了 / 数据库连不上
         判据：GET /health => 200；GET /posts => 200 且带 count 字段（真查到了数据库）。后端和数据库都活着。

[★ 命中] H8 线上 api 函数版本比本地旧（Day 23 未部署）
         判据：GET /favorites/extra => 404，返回体 {"ok":false,"error":"not found","receivedPath":"/api/favorites/extra"}。老版本 404 是手写的{ok:false,error:'not found',receivedPath}；本地 Day 23 已改成 fail() 会带 errorCode。线上没有 errorCode ⇒ 线上是 Day 22 那版。（注意：/api/health 是 Day 15 的独立函数，它的 deployedAt 不能代表 api 函数的版本，别拿它当判据。）

【收敛】
命中原因：H1 + H2 + H8

【因果链】
  前端 fill 表单 → 点发布
    → fetch('/api/posts?as=verified')  ← H1 相对路径，发到静态托管
      → 静态托管没有 /api → 404（这就是截图和Console 里那条 404 的来源）

  就算把 H1 修成 API_BASE 绝对地址，仍会 404：
    → 请求进到云函数 → H2 路由表里没有 POST /posts → 自家函数 404
      （返回体里的 receivedPath 就是证据，说明网关已经放行了，不用改绑定）
